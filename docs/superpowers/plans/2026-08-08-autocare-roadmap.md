# AutoCare+ Delivery Roadmap (Master Plan Index)

**Goal:** Ship AutoCare+ v1.0 — full feature set (C-06): NestJS API, Next.js web (staff/admin/public), two React Native apps (member, field), iOS-first.

This roadmap sequences the build into phases of vertical slices. **Each phase gets its own detailed implementation plan** in `docs/superpowers/plans/` when it begins; only Phase 0's plan exists so far. Spec of record: `AutoCare+ Docs/` vault. Approach decisions: `docs/superpowers/specs/2026-08-08-autocare-implementation-approach-design.md`.

## Sequencing rules

- Phases are strictly ordered; each ends with a demonstrable end-to-end flow on iOS simulator + web + API.
- Wave mapping from `13 Constraints and Risks` §13.2: Phases 0–5 ≈ Wave 1 (the spine), Phase 6 ≈ Wave 2, Phase 7 ≈ Wave 3. Nothing is de-scoped (C-06).
- **Week-1 risk burn-down (R-01):** the Firebase↔NestJS auth exchange is proven inside Phase 0 before any feature work.
- **External lead times started now, not at their phase:** PayMongo merchant application (R-04, needed Phase 2), Apple Developer Program enrollment (needed Phase 0 for TestFlight).
- Open product decisions D-1→D-10 use the documented defaults; all are configuration, so later sign-off never forces rework.
- Android stays compiling in CI throughout; device QA deferred to Phase 8 (iOS-first decision).
